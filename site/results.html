Test strategy

UI / E2E: Python + Playwright + Pytest, Page Object Model, Chromium / Firefox / WebKit

API: Pytest + requests, schema validation, negative cases

Unit: payroll and overtime rules in TypeScript (node --test)

Assistant evals: Pytest against a golden dataset: correctness, hallucination and prompt-injection checks (DeepEval-ready)

Accessibility: axe-core on every screen

CI release gate: GitHub Actions runs clean vs bugged; the release is blocked unless every planted bug is caught
